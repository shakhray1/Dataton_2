# 💸 Прогнозирование дохода клиента банка | Хакатон-практика 2026

**Команда:** «Альфачи»  
**Участники:** Анисов Б.К., Баньков Я.А., Красавина А.Г., Шахрай Н.С.  
**Целевая метрика:** WMAE (Weighted Mean Absolute Error)

## 📌 О проекте
Данный репозиторий содержит решение для хакатона по прогнозированию дохода клиентов на основе анонимизированных транзакционных, кредитных и демографических данных. 

Решение построено на **двухступенчатой архитектуре (Base + Residual)**, которая обеспечивает робастность к выбросам и сдвигу распределения (Covariate Shift).

## 🏗 Архитектура решения

1. **Базовая модель (Base LightGBM):** Обучается на полном наборе признаков (~396 фичей) с L1-loss (MAE) для устойчивости к экстремальным доходам.
2. **CDF-классификаторы:** Набор бинарных классификаторов, предсказывающих вероятность превышения доходом заданных порогов (от 50k до 1M). Якорят модель и защищают от аномалий.
3. **Модель-поправка (Residual LightGBM):** Обучается на предсказание ошибки (OOF) базовой модели. Использует компактный набор из 86 лучших признаков для предотвращения переобучения.
4. **Сборка (Inference):** 
   ```python
   final_pred = clip((base_pred + strength * correction), 20000, 1500000)
   ```
   *Коэффициент `strength` подбирается динамически (Grid Search).*

## 🧬 Feature Engineering & EDA
- **Кросс-валидация:** Expanding Window Cross-Validation для имитации реальных условий и защиты от утечек (Data Leakage) во времени.
- **Интеллектуальная импутация:** Значения `first_salary_income` восстанавливаются через изолированную ML-модель с 5-Fold кросс-валидацией.
- **Ratio-метрики:** Финансовые показатели (долговая/ликвидная нагрузка, утилизация кредитного лимита).
- **Семейные агрегации:** Вычисление средних и максимальных значений по родственным группам признаков.
- **Salary Proxy:** Синтез устойчивой оценки дохода на основе консенсус-медианы из нескольких источников и расчет уверенности (confidence).
